# react-video-kit

A composable, plugin-first React video player inspired by the iOS player.

> **Version 4 is in development on this branch and isn't published yet.** The stable release is 3.x, documented in [`packages/core/README.md`](./packages/core/README.md) and maintained separately.

## Repository

| Path | Contents |
| --- | --- |
| `packages/core` | The published `react-video-kit` package |
| `apps/docs` | Documentation site and browser test fixtures |
| `packages/eslint-config`, `packages/typescript-config` | Shared configuration |

See [`CONTRIBUTING.md`](./CONTRIBUTING.md) to get started.
