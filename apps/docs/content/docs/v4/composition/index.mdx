## Which one to use

| Choice | [Ready-made](/docs/v4/composition/player) | [Styled parts](/docs/v4/composition/parts) | [Headless](/docs/v4/composition/headless) |
|---|---|---|---|
| Import | `react-video-kit/player` | `react-video-kit` | `react-video-kit/primitives` |
| You write | One component | The layout | The layout and all CSS |
| Skin | Included | Included | None |
| Good for | Most players | A different layout | A design system of your own |

You can mix them too. Any part works inside `VideoPlayer` as a child, and your own components can read state with [hooks](/docs/v4/hooks) at any layer.
