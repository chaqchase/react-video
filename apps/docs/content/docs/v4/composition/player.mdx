`VideoPlayer` arranges every control for you. It has no plugins of its own, so you decide what's in it and what you pay for.

<Demo slug="player" />

## Usage

```tsx
"use client";

import { defaultPlugins, VideoPlayer } from "react-video-kit/player";
import "react-video-kit/styles.css";

const plugins = defaultPlugins();

export function Player() {
  return <VideoPlayer src="/video.mp4" poster="/poster.jpg" plugins={plugins} />;
}
```

With no plugins at all, it's still a working player with play, volume, time, and a timeline. `defaultPlugins()` adds these:

| Plugin | Adds |
|---|---|
| [`idle()`](/docs/v4/plugins/idle) | Controls that hide when idle |
| [`gestures()`](/docs/v4/plugins/gestures) | Click to play, double-tap to seek |
| [`hotkeys()`](/docs/v4/plugins/hotkeys) | Keyboard shortcuts |
| [`recovery()`](/docs/v4/plugins/recovery) | Retries after network errors |
| [`captions()`](/docs/v4/plugins/captions) | The captions menu |
| [`speed()`](/docs/v4/plugins/speed) | The speed menu |
| [`quality()`](/docs/v4/plugins/quality) | The quality menu |
| [`pip()`](/docs/v4/plugins/pip) | Picture in picture |
| [`fullscreen()`](/docs/v4/plugins/fullscreen) | Fullscreen |

It's only a function returning an array, so add to it, or list your own instead. A captions list needs its options, so replace the default in that case:

```tsx
const plugins = [
  hls(),
  captions({ tracks: [{ src: "/en.vtt", language: "en", label: "English" }] }),
  ...defaultPlugins().filter((plugin) => plugin.name !== "captions"),
];
```

Importing `defaultPlugins` costs all nine plugins. Listing them yourself means you only pay for the ones you list.

## Add your own UI

Children render above the media and below the controls, so a title or a custom overlay goes here. Your children can use any [hook](/docs/v4/hooks).

```tsx
<VideoPlayer src="/video.mp4" plugins={plugins}>
  <h2 className="absolute top-3 left-4 text-white">The long ridge</h2>
</VideoPlayer>
```

## Configure the video element

`media` passes props through to the `<video>`, including its events. `tracks` takes `<track>` elements.

```tsx
<VideoPlayer
  src="/video.mp4"
  media={{ loop: true, crossOrigin: "anonymous", onEnded: () => showNext() }}
/>
```
